## 接口与网格

`decay_oop.py` 提供题目要求的 `Decay` 类、属性、静态方法与类方法。
所有计算属性均现算；数值解采用预分配 NumPy 数组逐步 Euler 迭代，无缓存，也不在循环中拼接列表。
`N0`、`tau`、`dt` 必须为有限正数，`t_max` 为有限非负数；非法赋值抛出 `ValueError`。
网格严格使用 `t[k] = k * dt`；总时长不是步长整数倍时，仅保留不超过总时长的完整步，不增加不等长末步。
浮点整数倍端点允许机器精度的舍入偏差；`t_max = 0` 时仅返回初值。

## 分析题（6 行）

1. 当 0 < h = Δt/τ < 1 时，ln(1−h) < −h，所以 N0(1−h)^k < N0 exp(−kh)（k > 0）；误差是系统性负偏差，t = 0 时为零。
2. 上述符号结论适用于本题正常步长，并非所有步长；h > 1 后数值解会变号，不能再套用对数不等式。
3. 固定时间区间内 Euler 全局误差为 O(Δt)，log-log 拟合斜率接近 1、减半步长误差比趋于 2，均为一阶收敛的数值证据，而非单独的严格证明。
4. 若改为每步乘 exp(−Δt/τ)，网格点上无截断误差；右图只剩浮点舍入误差，无稳定的一阶趋势，零误差点不能在 log 轴显示。
5. Δt = 2.5 s 时放大因子为 −1.5，数值解交替变号且幅度每步增大 1.5 倍；实验得到 N(25) = 5766.5039，明显偏离衰变。
6. 渐近稳定需 |1−Δt/τ| < 1，即 0 < Δt < 2τ；Δt = 2τ 等幅振荡不衰减，超过则发散；保持非负还需 Δt ≤ τ。
